
# Python Programming

## What is Python?
Python is a popular programming language. It is easy to learn and use.

## Why do we use Python to program mBot2?
We use Python to give instructions to mBot2 and control its movements and functions.

## What is a Python comment?
A comment is a note in the code. It starts with the **# symbol** and is not executed.

## What is the purpose of displaying text on a screen?
Displaying text helps us show messages and information to the user.

## Three simple examples of Python code

1. Displaying a message:
   print("Hello World")

2. Creating a variable:
   name = "mBot2"

3. Adding numbers:
   print(5 + 3) 

Python helps us create programs and control devices.

*Python is easy to understand for beginners.*
